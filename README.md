# 绝对色感

方阵里只有一块颜色不一样。点中它，就进入下一关。

第 1 关是 3×3，差别明显。第 2 关是 4×4，差别收一档。之后每关边长加一，直到 8×8；格子不再变多之后，色差继续变小。每一盘的底色、差异方向和那一块的位置都重新随机。

色差按人眼比较均匀的方式计算，不按红绿蓝数值硬减。第 1 关仍是同一种颜色，只是有一块明显更亮或更艳。之后有时只差明暗，有时只差纯度，有时色相也偏开一点。

## 怎么玩

三条命。点错会失去一条命，并标出正确的那一块，然后仍停在当前关。答得越快、连对越多，得分越高。顶部的速度加成会在几秒内走完，走完仍然可以作答。

最佳关卡和得分记在本机。菜单里可以清除纪录。

空格开始，R 重来，esc 回到开始画面。

## 生成

在这个目录运行：

```bash
./build.sh
```

会在上一级目录生成「绝对色感.app」。
